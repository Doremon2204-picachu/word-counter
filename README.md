# Word & Line Counter CLI

A simple Node.js CLI application that reads a text file and prints the total number of lines, words, and characters.

## Setup & Usage

1. Clone the repository:
   ```bash
   git clone <https://github.com/Doremon2204-picachu/word-counter>
   cd word-counter
   ```
   2. Run the application:
   ```bash
   npm start sample.txt
    ```
